# Розширення «У Pippo»

Виділи слово чи речення на сайті або в PDF → правий клік → **➕ У Pippo** (або `Alt+Shift+P`).
Відкриється вікно Pippo з «✨ Слово з речення».

## Встановлення (Chrome / Edge)

1. `chrome://extensions` (або `edge://extensions`) → увімкни **Режим розробника**.
2. **Завантажити розпаковане** → вибери теку `extension/`.
3. Якщо Pippo працює не на `http://localhost:3700` — вкажи адресу в «Параметрах» розширення.
4. Для PDF, відкритих із диска (`file://`), у «Відомостях» розширення увімкни «Дозволити доступ до URL-адрес файлів».

Після змін у коді — кнопка ⟳ на картці розширення.

Іконки `icons/icon*.png` зроблені з `icons/pippo.svg` (та сама пташка, що в `public/app.js`).
Щоб перемалювати — відкрий SVG у headless Chrome з `--screenshot --window-size=N,N --default-background-color=00000000`.

## Як воно працює

- Змін на сервері й токенів не потрібно: розширення просто відкриває `#/dict?capture=…`
  у вікні Pippo, де ти вже увійшов (cookie). Якщо вхід не виконано — спершу увійди.
- **На звичайних сайтах** виділене слово береться разом із реченням навколо, як у закладці.
- **У PDF** розширенню видно лише сам виділений текст, без речення. Тому **виділяй усе речення** —
  Pippo відкриє його, і ти клікнеш потрібне слово (Shift + клік — фраза).
  Переноси (`leav-⏎es`) і розірвані рядки склеюються автоматично.
- Виділення до 4 слів вважається словом чи фразою, довше — реченням.
- Вікно Pippo одне: наступне слово відкривається в ньому ж.
- Гаряча клавіша міняється на `chrome://extensions/shortcuts`. У PDF вона не бачить виділення —
  там користуйся контекстним меню.
