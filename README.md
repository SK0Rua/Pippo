# 🐣 Pippo

Особистий словник із тренуваннями. Користувач реєструється, створює словники,
додає слова й ганяє їх у тестах, а пташка Pippo підбадьорює.

## Запуск

```bash
npm install
npm start          # http://localhost:3700
```

Потрібен Node.js ≥ 22.13 (використовується вбудований `node:sqlite`, окрема БД не потрібна).
Дані зберігаються в `data/pippo.db`. Змінні середовища (можна покласти у `.env`, він не йде в git):

| Змінна | Що робить |
| --- | --- |
| `GEMINI_API_KEY` | ключ Google AI Studio — автозаповнення карток з урахуванням контексту |
| `GEMINI_MODELS` | ланцюжок моделей, за замовчуванням `gemini-3.1-flash-lite,gemini-3.5-flash-lite,gemini-flash-lite-latest` |
| `PIPPO_ADMIN` | імена адміністраторів через кому — вони бачать сторінку 📊 «Адмінка» |
| `AI_WORDS_PER_HOUR` / `AI_WORDS_PER_DAY` / `AI_REQUESTS_PER_HOUR` | ліміти ШІ на акаунт (60 / 300 / 30) |
| `AI_WORDS_PER_DAY_TOTAL` | спільний денний ліміт на весь сервер (2000) |
| `PORT`, `PIPPO_DB` | порт і шлях до бази |
| `NODE_ENV=production` | додає `Secure` до cookie |

## Тести

```bash
npm test
```

`scripts/test-api.js` піднімає сервер на базі в пам'яті (`PIPPO_DB=:memory:`) і перевіряє 45 сценаріїв:
авторизацію, ізоляцію чужих даних, слова та імпорт/експорт, правила тренування й нарахування зерняток
(ліміти, захист від «фарму» та швидких відповідей) магазин (ціну рахує сервер, підроблені `price`/`free` ігноруються), скасування видалення, пошук, ліміти ШІ та доступ до адмінки.

## Ліміти ШІ та адмінка

- Рахуються **слова**, а не запити: автопереклад = 1, «кілька слів одразу» = кількість слів, пошук слів у тексті = 10.
  За замовчуванням 60 слів/год і 300/добу на акаунт, 30 запитів/год, плюс спільний запобіжник 2000 слів/добу на сервер.
- Витрата записується **до** звернення до Gemini, тож повторами ліміт не обійти; невдалі спроби позначаються для статистики.
- `PIPPO_ADMIN=ім'я` відкриває сторінку `#/admin`: користувачі, активність за 30 днів, навчання, економіка зерняток,
  популярні паки й навантаження на ШІ. Доступ перевіряє сервер (403 для решти).

## Слово з речення (Gemini)

- **✨ З речення** у словнику: встав речення, натисни на слово (Shift + клік — фраза), і Pippo заповнить
  початкову форму, переклад саме в цьому значенні, транскрипцію та приклад. Інші значення можна дописати одним кліком.
- **Автопереклад**: у формі додавання слова залиш переклад порожнім — Pippo підставить найуживаніші значення, приклад і транскрипцію, запропонує виправити описку; Enter — додати.
- **📝 Кілька слів одразу**: список до 30 слів (з нового рядка або через кому) → Pippo заповнює картки для всіх, відомі слова позначаються, перед додаванням усе можна виправити.
- **🔎 Знайти в тексті всі слова** — з абзацу Pippo вибере слова й ідіоми, які варто вивчити, з рівнем CEFR; уже відомі позначаються.
- **🔖 Закладка «У Pippo»** (сторінка «Прогрес»): виділи слово на будь-якому сайті, натисни закладку — відкриється Pippo з цим словом і реченням.
- **🧩 Розширення для Chrome** (`extension/`): те саме через контекстне меню «➕ У Pippo» або `Alt+Shift+P`, і працює також у PDF, де закладка безсила. Встановлення — [extension/README.md](extension/README.md).
- Якщо модель перевантажена чи мовчить 4 с, паралельно запитується наступна; без ключа або коли Gemini недоступний — простий переклад через MyMemory.

## Що вміє

- **Акаунти**: реєстрація/вхід, паролі хешуються через scrypt, сесія в HttpOnly-cookie.
- **Словники**: кілька словників з парами мов, пошук, фільтри (нові / вчу / вивчені / обрані), редагування, перенесення слів.
- **Імпорт / експорт** CSV (`слово;переклад;приклад`, також Tab, ` - `, `=`), дублікати пропускаються.
- **5 режимів тренування**: вибір із 4 варіантів, написання, картки, пари на час, диктант (озвучка браузера).
- **Розумне повторення** (система Лейтнера): 6 поличок з інтервалами 0 → 1 → 3 → 7 → 14 → 30 днів; помилка повертає слово на 2 полички назад.
- **Поблажлива перевірка**: регістр, пунктуація, `to`/артиклі, кілька варіантів перекладу через кому, дрібні описки зараховуються; кнопка «Моя відповідь теж правильна» для синонімів.
- **Мотивація**: XP і рівні, серія днів, денна ціль із конфеті, «слово дня», список найскладніших слів, «Повторити помилки» після тесту.
- **Прогрес**: теплова карта активності, полички пам’яті, історія тренувань, точність.
- **Дрібниці зручності**: виправити картку можна прямо з тренування (✎ у підказці), видалене слово чи словник
  повертаються кнопкою «Скасувати» протягом 90 с (разом із прогресом), пошук шукає і в інших словниках,
  у заголовку словника видно прогрес (для куплених паків — прогрес пака).
- Темна тема, мобільна версія, гарячі клавіші (1–4, Enter, пробіл).

## Зернятка 🌾 і магазин паків

- **Зернятка** даються за справжнє навчання: +2 за слово, яке пора повторити (у картках +1), +1 за нове слово (до 10 на день), +5 за вивчене слово, +10 за денну ціль, 25/75/200 за серію 7/30/100 днів. За навчання — **не більше 50 🌾 на день**.
- Захист від накруток: журнал `grains` з разовими ключами, «сьогодні» рахує сервер за часовим поясом користувача, відповіді приймаються лише в межах сесії тренування й не частіше ~1 на 0.7 с, «помилитись → відповісти правильно» того ж дня не платить.
- **Магазин**: 58 паків (теми, професії, ситуації, мовні явища, рівні, підручники) — разом ~3 400 слів; серед них словник English File 4e Intermediate, розбитий на 10 паків за File 1–10 книжки. Перший пак до 50 слів — безкоштовно, пак дня −30%, відомі слова зменшують ціну, за повністю вивчений пак повертається 25% ціни. Куплений пак стає окремим словником.
- **Пак із підручника**: pdfplumber (розбір по координатах колонок — `pdftotext` губить IPA) → `scripts/build-wordlist-pack.js <extracted.json> <packId> [--split]` (`--split` робить окремий пак на кожен File книжки) перекладає слова через Gemini, а транскрипцію й приклади бере з книжки. Переклад кешується в `packs/.<packId>.cache.json`, тож після вичерпаного ліміту API скрипт можна просто запустити ще раз.
- Зміст паків — `packs/<id>.json`, план і описи — `scripts/pack-plan.js`, іконки — `public/packs/<id>.svg` (`node scripts/make-icons.js`). Після змін: `node scripts/check-packs.js`.

## Структура

```
server.js      Express API (auth, decks, words, quiz, shop, stats)
economy.js     зернятка: нарахування, ліміти, журнал
packs.js       каталог паків і ціни
ai.js          Gemini: слово з речення
db.js          схема SQLite і міграції
packs/         зміст паків слів
scripts/       план паків, перевірка, генерація, іконки
extension/     розширення Chrome «У Pippo»
public/        клієнт без фреймворків: app.js, shop.js, capture.js, text.js, styles.css
```
