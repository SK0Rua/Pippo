# Паки слів: зміст, ціни, свої набори

## Що це

58 готових наборів слів англійська → українська, ~3 400 слів. Кожне слово має переклад,
транскрипцію й речення-приклад. Куплений пак стає окремим словником.

| Категорія | Паків | Приклади |
| --- | --- | --- |
| 🧭 Теми | 15 | Аеропорт, Ресторан, Дім і побут, Емоції та характер |
| 💼 Професії | 13 | IT, Медицина, Логістика, Догляд за людьми, Водій |
| 🎯 Ситуації | 7 | Співбесіда, Переїзд за кордон, Small talk, Ділове листування |
| 🧩 Мовні явища | 7 | Фразові дієслова, Ідіоми, Сленг, Хибні друзі перекладача |
| 📈 Рівні | 6 | Основа A1–C1, IELTS |
| 📘 Підручники | 10 | English File 4e Intermediate, File 1–10 |

## Як влаштовано

```
scripts/pack-plan.js      метадані: id, тип, рівень, розмір, назва, опис
packs/<id>.json           зміст: [["to leave","залишати","/liːv/","She left early."], ...]
public/packs/<id>.svg     іконка (генерується)
packs.js                  каталог і ціни
```

Слова зберігаються компактними масивами `[слово, переклад, транскрипція, приклад]` —
формат об'єктів теж підтримується.

Додати свій пак: запис у `pack-plan.js` → файл у `packs/` → `node scripts/make-icons.js` →
`node scripts/check-packs.js` → перезапуск сервера.

## Перевірка змісту

`node scripts/check-packs.js [id...]` перевіряє кожен пак:

- кількість слів збігається з планом;
- немає дублів (порівняння без «to» й регістру);
- переклад українською, без російських літер;
- транскрипція у форматі `/…/`;
- **слово справді є у своєму прикладі** — з урахуванням форм (`leave → left`, `give up → gave up`,
  `study → studied`, `lose your temper → lost his temper`);
- паки «Основа» A1–C1 не перетинаються між собою.

Це швидка перевірка без мережі, тож ганяй її після будь-якої зміни змісту.

## Ціни

```
ціна = кількість слів × ціна_за_слово(рівень) × знижка_за_обсяг, округлено до 5
```

| Рівень | 🌾 за слово |
| --- | --- |
| A1 | 1.6 |
| A2 | 1.8 |
| B1 | 2.2 |
| B2 | 2.6 |
| C1 | 3.0 |

Знижка за обсяг — плавна: `max(0.7, 1 − (слів − 20) × 0.0022)`. Плавна навмисне: на «сходинках»
виходило, що пак на 46 слів коштує дорожче за пак на 51.

Що змінює ціну для конкретного користувача:

- **Перший пак до 50 слів — безкоштовно** (разово, ключ `first-pack`).
- **Пак дня — −30%**, однаковий для всіх, змінюється щодня.
- **Уже відомі слова** не дублюються в новому словнику, і ціна зменшується пропорційно.
- **Вивчив пак повністю** — повертається 25% ціни.
- Якщо словник пака видалили, повторна покупка безкоштовна.

Орієнтир: пак на 20 слів ≈ 40 🌾 (день тренувань), на 100 слів ≈ 185 🌾 (2–3 дні).

## Іконки

`node scripts/make-icons.js` малює всі іконки з одного набору правил: заокруглений квадрат
кольору категорії плюс тематичний малюнок. Кольори: теми — помаранчевий, професії — фіолетовий,
ситуації — бірюзовий, мовні явища — рожевий, рівні — зелений, підручники — синій.

Рівневі паки отримують значок із написом (A1, B2…), паки підручника — книжку з номером розділу.

## Генерація через Gemini

`node --env-file=.env scripts/generate-packs.js [id...]` — порціями по 25 слів, з локальними
перевірками та другим проходом «рецензування» моделлю.

**Обмеження, з яким довелося жити:** безкоштовний `gemini-3.5-flash` дає лише 20 запитів на добу,
а lite-моделі для такої задачі надто слабкі — у «Хибних друзях перекладача» вони запропонували
*toxic*, *resin*, *replica*, які ними не є. Тому три паки згенеровані моделлю, а решта написані
вручну й перевірені скриптом.

## Пак із підручника

Із PDF-словника підручника пак робиться так:

1. **Розбір PDF** — pdfplumber по координатах колонок. `pdftotext` не годиться: він губить символи
   транскрипції (`/bin/` замість `/ˈəʊbəʒiːn/`).
2. **Переклад** — `node --env-file=.env scripts/build-wordlist-pack.js <extracted.json> <packId> [--split]`.
   Транскрипція й приклади беруться з книжки, перекладається лише значення — з урахуванням
   прикладу й теми розділу.
3. **Кеш** — `packs/.<packId>.cache.json`. Якщо денний ліміт API вичерпався, просто запусти скрипт
   ще раз: уже перекладене не чіпається.
4. **`--split`** робить окремий пак на кожен File книжки, щоб вони збігалися з юнітами курсу.

Так зроблено «English File 4e Intermediate»: 770 слів, розбиті на 10 паків по 15–123 слова.
